Project
Superstore Sales & Profit Story
This project analyzes the Sample Superstore retail dataset and turns the results into a visual narrative for a non-technical audience.
Main techniques
- Data cleaning and feature engineering
- Time-series analysis
- Category/sub-category comparison
- Region-category heatmap
- Discount vs. profit scatter analysis
- Profit distribution and outlier analysis
- Interactive Plotly visualization
Visualizations
1. Monthly Sales and Profit Trend
2. Sales by Sub-Category
3. Region × Category Profit Heatmap
4. Discount vs Profit Interactive Scatter
5. Profit Distribution Box Plot
6. Interactive Regional Sales Chart
How to run
pip install -r requirements.txt
jupyter notebook notebooks/week2_visualization.ipynb
The notebook downloads the public Sample Superstore CSV automatically when executed.
Dataset source
The Sample Superstore dataset is publicly distributed for data-analysis and visualization practice. The project notebook references a public GitHub copy of the CSV.
